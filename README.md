# CIFI Mod Points Planner

An unofficial fan tool for planning Loop Mod purchases in Cell: Idle Factory Incremental (CIFI). It is not affiliated with CIFI or its developers.

The buy order this page produces is the Mod Tree Cultivator spreadsheet's buy order. This project does not replace that sheet, and it does not claim the work that went into it.

## What this fan tool is

[leosans-eng](https://github.com/leosans-eng) wrote this page so the sheet's scoring can be run locally. You enter the mod points from one loop reset and get a buy order to check off. Nothing is read from the game. Levels change only when you enter them or check a row off.

Bugs and suggestions: [https://github.com/leosans-eng/cifi-mod-points-planner/issues](https://github.com/leosans-eng/cifi-mod-points-planner/issues)
